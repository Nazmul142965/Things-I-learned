# 📚 Things I Learned
A personal sandbox and learning tracker containing code snippets, lab assignments, and small exercises across various programming languages and computer science concepts. 

I use this repository as my personal coding wiki to track my progress, test syntax, and store reusable code.

## 🗂️ How This Repository is Organized
Instead of creating a new repository for every small script, everything here is categorized into folders by **Topic**, **Language**, or **Course**. 

Navigate through the folders above to find:
* **Core Languages:** Syntax practice and small scripts (e.g., C, Java, Go, Assembly).
* **Computer Science Concepts:** Implementations of core theories (e.g., DSA, Networking).
* **Applied Engineering:** Lab reports, system design, and hardware code (e.g., Embedded Systems, Graphics & Animation, SQL).

Inside each folder, you will find its own specific `README.md` (where applicable) explaining what those specific files do.
